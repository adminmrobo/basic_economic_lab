# 경제학 원론 연구실 — 생활 속에서 질문하고 실험으로 확인하는 경제학의 이해

> 모자란 것을 어떻게 나눌까? 그 선택들이 만나 가격과 나라 경제는 어떻게 움직일까?

**본 강의는 한국체육대학교 교양과정의 「경제학의 이해」, 「생활 속의 경제학」 강의노트를 기반으로 제작됐습니다.**

중간고사 범위는 「생활 속의 경제학」 강의노트(2025-2학기, 제1장~제7장), 기말고사 범위는 「경제학의 이해」 기말고사 자료집(2025-2학기)을 뼈대로 하고, 부족한 부분은 「미시경제원론 강의노트 4강(2)」(2015)과 「현대경제학원론 강의노트 — 미시편」으로 보충한 **비전공 독자용 강의실 해설 시리즈**입니다. 형식은 [미시경제학 연구실](https://adminmrobo.github.io/micro_economics/)과 같고, 경제학 원론이라 재정학(외부효과·공공재·소득분배)과 거시경제(GDP·실업·인플레이션·재정·통화정책)까지 다룹니다.

- **바로 보기:** https://adminmrobo.github.io/basic_economic_lab/
- 글 · 안상선 ((주)M-Robo 대표) · [저자 소개](https://adminmrobo.github.io/who_am_i/who_am_i.html)

## 강의실 식구

| 자리 | 캐릭터 | 하는 일 |
|---|---|---|
| 교수 | 박사 | 상황 질문으로 문을 열고, "이 숫자는 이런 뜻"으로 정리 |
| 조교 | 초파리 연구원 · 주판봇 | 의심하는 조교와 성급하게 확신하는 조교. 장마다 숫자로 대결 |
| 수강생 | 하루 · 시아 · 모아 | 하루는 수식을 대신 질문, 시아·모아는 대결 심판 |
| 뒷자리 수강생 | X1 · X2 · X3 | 아직 공개되지 않은 식구. 질문과 실험 거들기 |

## 정확성과 감사

- 원자료에서 뜻이 불분명하거나 틀린 표현 46건을 바로잡았습니다(예: 교차탄력성의 기준 1 → 0, 정성적/정량적 영어 뒤바뀜, 균형 이동 방향 오류, 판매자 과세 설명의 주체 오류). 목록과 검산 기록은 [docs/AUDIT_REPORT.md](docs/AUDIT_REPORT.md)와 각 쪽 바닥글 "원자료와 다르게 쓴 곳"에 있습니다.
- 모든 예시값은 다시 계산했고, 새로 만든 설명용 모형은 각 쪽 바닥글에 밝혔습니다. CH11은 교육용이며 투자 자문이 아닙니다.
- 표지 15장은 16비트 RPG 픽셀아트·낮의 강의실 지시문([docs/IMG_PROMPTS_all.md](docs/IMG_PROMPTS_all.md))으로 Genspark에서 그렸고, 480×270 격자를 4배 정수배로만 키운 무손실 WebP로 넣었습니다(2026-11-23).

```
index.html · tower.html            목차 · 3D 시장 보기
01_…html ~ 11_…html                장 해설 (한 파일)
05m_… · 11f_…html                  중간·기말 요약정리 및 퀴즈
practice/index.html                마지막 장 · 실전 연습장

assets/og/cover_*.jpg              공유 미리보기(대체 이미지)
docs/AUDIT_REPORT.md               감사보고서
docs/IMG_PROMPTS_all.md            표지 그림 지시문 (Genspark용)
docs/genspark/                     Genspark 요청문(대화별)·저장 이름 체크리스트
src/pages/*.py                     페이지 데이터
src/build/                         빌드 도구 (sims_econ.js 실험 33개, dash_econ.js 대시보드 11개, practice.py 실전 연습장, tower.* 3D 시장)
```

다시 빌드하기: `python3 src/build/build.py . && python3 src/build/practice.py . && python3 src/build/make_docs.py`

그림으로 먼저 보기(장마다 2장): Genspark 요청문은 `docs/genspark_ill/요청문.md`. 받은 PNG를 `src/build/ill_in/`에 넣고 `python3 src/build/import_ill.py && python3 src/build/build.py .`

그래프 글자 겹침 검사: `node src/build/check_text.js <html…>`(슬라이더 끝값은 `EXT=max`·`EXT=min`), 연습장은 `node src/build/check_practice.js practice/index.html`

표지 반영: Genspark 그림을 `src/build/covers_in/cover_<키>.png`로 넣고 `python3 src/build/import_covers.py` 실행 후 다시 빌드. 요청 꾸러미 다시 만들기: `python3 src/build/make_genspark_pack.py <fruitfly-lab-expressions 경로>`

캐릭터 이름·설정·그림의 저작권은 안상선(개인)에게 있으며 허락 없이 쓸 수 없습니다. 캐릭터 그림: [fruitfly-lab-expressions](https://github.com/adminmrobo/fruitfly-lab-expressions).
